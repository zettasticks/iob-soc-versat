What problems do we have to solve?

First of all, lets assume that we have N units and that all N units need to be programmed to do the exact same thing except that we then divide the work evenly (as best as we can) among the units.

Every unit is responsible for producing a certain number of addresses given the loops that we define beforehand.

Assuming that we have the module:

Generator gen[N];
Mem m[N];

gen[0..N] -> m[0..N];


Lets start simple. 1D

for i 0..N {
   for x 0..4 {
      gen[i] = x;
   }
}

This produces the values 0,1,2,3.

and is equivalent to:

for x 0..4 {
   gen_0 = x;
}
for x 0..4 {
   gen_1 = x;
}

How do we divide the work evenly for this case? We only have two direct options, either by doing 0,1 / 2,3 or 0,2 / 1,3

something like

// Handles 0,1 / 2,3
gen i 0..N {
   for x 0..2 {
      gen[i] = i * 2 + x;
   }
}

// Handles 0,2 / 1,3
gen i 0..N {
   for x 0..2 {
      gen[i] = x * 2 + i;
   }
}

What if the work is uneven?

First of all, if we make it so that the write portion only writes the correct amount of data, then the work being uneven should not cause any problems right?.
At the same time if we could have Versat automatically manage this or provide a easy way of expressing this concept it would be awesome.

For now lets not worry about uneven workloads. It is enough having this working for even work.
